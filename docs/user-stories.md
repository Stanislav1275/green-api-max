# User stories и тест-кейсы

Каждый тест-кейс автоматизирован. Номер кейса стоит в начале имени теста, поэтому находится поиском:
`TC-2.1` → [`src/app/stories/create-chat.test.tsx`](../src/app/stories/create-chat.test.tsx).

- **Интеграционные тесты** (`src/app/stories/*.test.tsx`) рендерят всё приложение в jsdom, GREEN-API подменён MSW-моком.
- **E2E** (`e2e/*.spec.ts`, Playwright) проходят основные сценарии в настоящем браузере в демо-режиме.

Термины: _инстанс_ — аккаунт GREEN-API, подключённый к MAX; _собеседник_ — владелец номера, которому пишет пользователь.

---

## US-1. Вход по данным GREEN-API

> Как пользователь, я хочу ввести `apiUrl`, `idInstance` и `apiTokenInstance`, чтобы открыть свой чат MAX.

| ID      | Шаги                                        | Ожидаемый результат                                                                    |
| ------- | ------------------------------------------- | -------------------------------------------------------------------------------------- |
| TC-1.1  | Ввести корректные данные, нажать «Войти»    | Открывается экран «Чаты», в шапке номер инстанса                                       |
| TC-1.2  | Нажать «Войти» с пустыми полями             | Под каждым полем подсказка, запрос к GREEN-API не отправляется                         |
| TC-1.3  | Ввести `idInstance` с буквами               | «idInstance состоит только из цифр»                                                    |
| TC-1.4  | Ввести `apiUrl` со слешем в конце           | Вход успешен, запросы идут без двойного слеша                                          |
| TC-1.5  | Ввести неверный токен (сервер отвечает 401) | Уведомление «Неверный idInstance или apiTokenInstance», пользователь остаётся на входе |
| TC-1.6  | Инстанс не авторизован в MAX                | Предупреждение с подсказкой отсканировать QR-код                                       |
| TC-1.7  | В настройках инстанса задан `webhookUrl`    | Предупреждение: очистить `webhookUrl`                                                  |
| TC-1.8  | Входящие уведомления выключены              | Предупреждение: включить уведомления                                                   |
| TC-1.9  | Сервер вернул ошибку конкретного поля       | Поле подсвечено, текст ошибки под ним, всплывающего уведомления нет                    |
| TC-1.10 | Сервер недоступен                           | Уведомление «Нет соединения с сервером GREEN-API…»                                     |
| TC-1.11 | Сервер ответил неизвестной ошибкой          | Уведомление «Произошла неизвестная серверная ошибка»                                   |
| TC-1.12 | Нажать «Войти» и дождаться ответа           | Пока идёт проверка, кнопка неактивна                                                   |

## US-2. Новый чат по номеру телефона

> Как пользователь, я хочу ввести номер получателя, чтобы начать с ним переписку.

| ID     | Шаги                                                            | Ожидаемый результат                                              |
| ------ | --------------------------------------------------------------- | ---------------------------------------------------------------- |
| TC-2.1 | Ввести `+7 (999) 123-45-67`, `8 999 123 45 67` или `9991234567` | Открывается чат «+7 999 123-45-67»                               |
| TC-2.2 | Ввести `12345` или `abc`                                        | Ошибка «Введите номер в формате +7 999 123-45-67», чат не создан |
| TC-2.3 | Ввести номер, для которого чат уже есть                         | Открывается существующий чат, дубля в списке нет                 |
| TC-2.4 | Войти впервые                                                   | Вместо списка подсказка «Введите номер получателя…»              |
| TC-2.5 | Открыть чат, затем выбрать другой в списке                      | Открывается выбранный чат, в списке он отмечен активным          |

## US-3. Отправка сообщения

> Как пользователь, я хочу написать текст и отправить его собеседнику в MAX.

| ID     | Шаги                                       | Ожидаемый результат                                                  |
| ------ | ------------------------------------------ | -------------------------------------------------------------------- |
| TC-3.1 | Написать «Привет», нажать Enter            | Сообщение справа со статусом «Отправлено», поле очищено              |
| TC-3.2 | Нажать Shift+Enter                         | В поле перенос строки, ничего не отправлено                          |
| TC-3.3 | Оставить поле пустым или из пробелов       | Кнопка «Отправить» неактивна, запроса нет                            |
| TC-3.4 | Отправить `  текст  `                      | В GREEN-API уходит `chatId: 79991234567@c.us` и `message: текст`     |
| TC-3.5 | Отправка упала на сервере                  | У сообщения статус «Не отправлено», всплывает уведомление с причиной |
| TC-3.6 | Отправить и смотреть, пока сервер отвечает | До ответа сервера статус «Отправляется»                              |
| TC-3.7 | Вставить текст длиннее 4000 символов       | В поле остаётся 4000 символов (лимит из спецификации API)            |
| TC-3.8 | Нажать кнопку «Отправить»                  | Работает так же, как Enter                                           |

## US-4. Получение ответа

> Как пользователь, я хочу видеть ответ собеседника в том же чате.

| ID     | Шаги                                                                           | Ожидаемый результат                                                  |
| ------ | ------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| TC-4.1 | Написать собеседнику, он отвечает (MAX присылает числовой `chatId`)            | Ответ появляется слева в том же чате, второго чата не появляется     |
| TC-4.2 | Написал новый контакт                                                          | В списке появляется чат с его именем и текстом, в шапке чата — номер |
| TC-4.3 | В очереди картинка, смена статуса, битое уведомление, затем текст              | Лишнее пропущено и удалено из очереди, текст показан                 |
| TC-4.4 | GREEN-API прислал уведомление о нашем же отправленном сообщении                | Сообщение не дублируется                                             |
| TC-4.5 | Пользователь написал собеседнику с телефона                                    | Сообщение показано в чате как исходящее                              |
| TC-4.6 | Получение уведомлений временно падает                                          | Приложение повторяет запросы, после восстановления сообщения доходят |
| TC-4.7 | Приходит сообщение в чат, который ниже в списке                                | Этот чат поднимается наверх                                          |
| TC-4.8 | Ответить в чат, созданный сообщением с телефона (номер собеседника неизвестен) | Сообщение уходит на MAX `chatId` этого чата                          |

## US-5. Сессия и выход

> Как пользователь, я хочу оставаться в чате после перезагрузки и выходить на чужом компьютере.

| ID     | Шаги                           | Ожидаемый результат                                                   |
| ------ | ------------------------------ | --------------------------------------------------------------------- |
| TC-5.1 | Войти и перезагрузить страницу | Открыт экран «Чаты», история на месте                                 |
| TC-5.2 | Нажать «Выйти»                 | Экран входа; данные входа и история удалены, опрос сервера остановлен |

## US-6. Мобильная версия

> Как пользователь телефона, я хочу переключаться между списком чатов и перепиской.

| ID     | Шаги                                | Ожидаемый результат                                             |
| ------ | ----------------------------------- | --------------------------------------------------------------- |
| TC-6.1 | Открыть чат, нажать «Назад к чатам» | Снова виден список чатов                                        |
| TC-6.2 | Открыть приложение на ширине 390px  | Виден либо список, либо чат, без горизонтальной прокрутки (E2E) |
